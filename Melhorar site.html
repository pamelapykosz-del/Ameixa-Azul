Montagem

Passo a passo

Organize o circuito por etapas para facilitar os testes.

01

Monte a alimentação

Conecte os trilhos da protoboard ao 5V e GND do Arduino.

02

Ligue os LEDs

Use resistores em série e identifique cada saída do semáforo.

03

Conecte o sensor IR

Ligue VCC, GND e SINAL. Neste projeto, o sinal é monitorado pelo pino D2.

04

Carregue e teste

Envie o código para o Arduino e aproxime um objeto do sensor para testar a mudança de fase.

⚠ Dica: antes de energizar o circuito, confira polaridade dos LEDs, resistores e conexões de 5V/GND.
Programação

Código C++ / Arduino

semaforo_ir.ino 
const byte SENSOR_IR = 2;
const byte CARRO_VERDE = 8;
const byte CARRO_AMARELO = 9;
const byte CARRO_VERMELHO = 10;
const byte PED_VERDE = 11;
const byte PED_VERMELHO = 12;

volatile bool pedidoTravessia = false;

void pedido() {
  pedidoTravessia = true;
}

void setup() {
  pinMode(SENSOR_IR, INPUT);
  pinMode(CARRO_VERDE, OUTPUT);
  pinMode(CARRO_AMARELO, OUTPUT);
  pinMode(CARRO_VERMELHO, OUTPUT);
  pinMode(PED_VERDE, OUTPUT);
  pinMode(PED_VERMELHO, OUTPUT);

  attachInterrupt(digitalPinToInterrupt(SENSOR_IR), pedido, FALLING);
}

void loop() {
  // Estado normal: carros liberados e pedestres parados.
  digitalWrite(CARRO_VERDE, HIGH);
  digitalWrite(PED_VERMELHO, HIGH);

  if (pedidoTravessia) {
    pedidoTravessia = false;

    digitalWrite(CARRO_VERDE, LOW);
    digitalWrite(CARRO_AMARELO, HIGH);
    delay(1000);

    digitalWrite(CARRO_AMARELO, LOW);
    digitalWrite(CARRO_VERMELHO, HIGH);
    digitalWrite(PED_VERMELHO, LOW);
    digitalWrite(PED_VERDE, HIGH);
    delay(4000);

    digitalWrite(PED_VERDE, LOW);
    digitalWrite(PED_VERMELHO, HIGH);
    digitalWrite(CARRO_VERMELHO, LOW);
  }
}
Diagnóstico

Solução de problemas

O sensor não detecta o objeto +

Confira VCC/GND, o fio de SINAL e ajuste o potenciômetro de sensibilidade do módulo IR.

O LED não acende +

Verifique a polaridade do LED, o resistor em série e se o pino configurado no código corresponde ao fio.

A interrupção não dispara +

No Arduino Uno, confirme que o sinal está no D2 e que o modo FALLING foi configurado.

O semáforo fica travado +

Revise as conexões e observe o Monitor Serial para identificar em qual etapa o programa parou.
